# Inaam Ullah

**Payload CMS Developer · Next.js · TypeScript**

Full-stack developer based in Pakistan, currently leading development at BrandBloom (US-facing agency). I build production websites and platforms on Payload CMS + Next.js + TypeScript — around 12 of them shipped over the last 2 years across SaaS, e-commerce, finance, medical, and service-business verticals.
